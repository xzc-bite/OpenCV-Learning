=============================================
            银行卡卡号识别系统
        基于 OpenCV 模板匹配实现
=============================================

一、项目简介
本项目采用传统计算机视觉技术，不依赖深度学习框架。
利用图像预处理、轮廓检测、形态学运算、模板匹配等算法，
实现银行卡卡号自动定位、字符分割、数字识别与结果可视化。
适合 OpenCV 入门学习、课程设计、视觉实战练习。

二、技术栈
    编程语言：Python 3.x
    核心库：OpenCV-Python、NumPy
    辅助库：imutils（轮廓排序、图像缩放）

三、项目目录结构
OpenCV利用模板匹配进行数字识别/
├── main.py         主程序代码
├── README.txt      项目说明文档
└── img/            图片文件夹（名称不可修改）
    ├── 模板.jpg    0~9数字模板（白底黑字，从左至右排序）
    └── 图片.jpg    待识别银行卡照片

四、环境依赖安装
打开终端/命令行，执行以下命令安装依赖：
    pip install opencv-python numpy imutils

五、运行说明
1. 将 模板.jpg、图片.jpg 放入 img 文件夹；
2. 使用 Python 运行 main.py；
3. 程序会依次弹出图像处理窗口，按下任意键切换窗口；
4. 运行结束后，控制台输出完整卡号，窗口展示标注结果。

六、整体算法流程
数字模板图 → 灰度化 → 反向二值化 → 轮廓提取 → 排序 → 标准模板库
银行卡原图 → 缩放 → 灰度化 → 礼帽运算 → 边缘检测 → 闭运算 → 二值化
轮廓检测 → 规则筛选 → 卡号定位 → 字符分割 → 模板匹配 → 结果绘制

七、分步原理详解
7.1 数字模板制作
    1. 灰度化：去除色彩干扰，简化计算
    2. 反向二值化：数字转为白色前景，背景转为黑色
    3. 轮廓检测：提取每个数字外轮廓
    4. 轮廓排序：从左到右排列，保证顺序 0~9
    5. 尺寸归一化：统一大小为 (57, 88)，保证匹配标准一致

7.2 银行卡图像预处理（核心）
    1. 图像缩放：统一宽度，固定算法参数
    2. 灰度化：去除彩色信息
    3. 礼帽运算：突出凸起卡号，压制背景干扰
    4. Sobel水平边缘检测：只保留水平边缘，过滤花纹干扰
    5. 像素归一化：提升图像对比度
    6. 闭运算：将单个数字连接为数字组，方便区域定位
    7. 二值化：转为纯黑白图像，过滤细小噪点

7.3 卡号区域筛选
    1. 提取图像所有外轮廓
    2. 宽高比筛选：4位数字组比例 2.5 ~ 5.0
    3. 尺寸筛选：限定宽、高范围，剔除干扰区域
    4. 区域排序：从左至右排列卡号组

7.4 字符分割与模板匹配
    1. 截取单组卡号区域，再次降噪、二值化
    2. 提取单个数字轮廓并排序
    3. 归一化模板匹配：逐一对比 0~9 模板，计算相似度
    4. 选取相似度最高结果作为识别数字

7.5 结果可视化
    每组数字识别完毕后统一绘制边框与文字，仅绘制一次，避免重叠错乱。

八、常见问题与解决
8.1 报错：can't open/read file
    原因：图片路径/文件名错误、未放入 img 文件夹
    解决：严格按照目录结构放置文件，文件名保持不变

8.2 报错：Assertion failed
    原因：图片读取为空、文件损坏
    解决：检查图片格式与完整性，建议使用 JPG 格式

8.3 检测不到卡号区域
    解决：微调代码中 宽高比、宽高尺寸 的筛选范围

8.4 数字识别错误
    解决：保证模板图片清晰、白底黑字，数字顺序为 0~9
