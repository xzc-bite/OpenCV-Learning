## 1. 项目简介
本项目是基于**传统计算机视觉（非深度学习）**的银行卡卡号自动识别系统。  
使用 **OpenCV + 模板匹配 + 轮廓检测 + 形态学处理**，从银行卡照片中自动：

- 定位卡号区域  
- 分割 4 组数字（每组 4 位）  
- 逐字符识别（0–9）  
- 在图上标注结果并输出完整卡号  

特点：**轻量、快速、可解释性强、无需训练、直接部署**，适合 CV 入门与工程实战。

6. 核心原理（详细）
整个系统分为 5 大阶段：
阶段 1：制作标准数字模板库
目的：让程序知道 0–9 长什么样。
读取白底黑字模板图（0123456789 从左到右）
灰度化：3 通道 → 1 通道，减少计算
反向二值化：数字变白、背景变黑，便于轮廓提取
轮廓检测：得到每个数字的外轮廓
轮廓排序：从左到右，保证顺序 0–9
统一尺寸：所有数字缩放到 (57, 88)，保证匹配一致性
最终得到一个0–9 标准数字模板库。
阶段 2：银行卡图像预处理（核心）
目的：把卡号 “凸显” 出来，把背景干扰压下去。
缩放：统一宽度为 600，避免图片大小不一
灰度化：去彩色，简化处理
礼帽运算（TopHat）：
突出亮区域（卡号是凸印，比背景亮），抑制深色背景干扰
Sobel 水平边缘检测：
只保留水平方向边缘，过滤垂直纹理、花纹干扰
归一化：像素值拉到 0–255，增强对比度
闭运算（膨胀 + 腐蚀）：
将 4 个相邻数字 “粘” 成一个矩形块，方便后续定位
二值化：图像变为纯黑白，去掉细小噪点
结果：卡号区域变成4 个清晰的白色矩形条。
阶段 3：轮廓检测 + 卡号区域筛选
预处理后会有很多轮廓（logo、日期、花纹、卡号），需要规则过滤：
找到所有外轮廓
计算每个轮廓的外接矩形（x, y, w, h）
宽高比筛选：卡号 4 位数字 → 宽高比 2.5 ~ 5.0
尺寸筛选：宽度 65–180，高度 15–40
从左到右排序：保证卡号顺序正确
最终筛选出 4 个卡号区域。
阶段 4：单字符分割 + 模板匹配识别
对每组 4 位数字：
提取 ROI（感兴趣区域）
二值化
轮廓检测 → 得到 4 个单数字轮廓
排序 → 保证从左到右
模板匹配（TM_CCOEFF_NORMED）：
把单个数字与 0–9 模板逐一比对
计算相关系数（越接近 1 越相似）
取最高得分对应的数字作为识别结果
得到每组 4 位数字，拼接成完整卡号。
阶段 5：结果可视化
在原图上为每组卡号绘制红色矩形框
在框上方标注识别出的数字（绿色文字）
输出最终图像并打印卡号
7. 算法流程图示
plaintext
模板图 → 灰度 → 反二值 → 轮廓 → 排序 → 0-9模板库
   ↓
银行卡图 → 缩放 → 灰度 → 礼帽 → Sobel → 闭运算 → 二值
   ↓
轮廓检测 → 筛选（宽高比/尺寸）→ 4组卡号区域
   ↓
每组分割为4个单数字 → 模板匹配 → 识别结果
   ↓
绘制矩形+文字 → 输出卡号

10. 常见问题
1. 读不到图片
检查路径：必须是 img/template.jpg、img/card.jpg
文件名不要中文、空格
2. 识别框乱跳 / 找不到卡号
调整礼帽 / 闭运算核大小
微调宽高比范围 2.5–5.0
3. 数字识别错
模板必须是白底黑字、清晰、无噪点
模板尺寸与卡面数字比例接近
