# OpenCV-Learning
银行卡卡号识别系统（OpenCV 模板匹配）
一、项目概述
本项目基于传统计算机视觉（CV）算法，不依赖深度学习框架，通过 OpenCV 实现银行卡卡号的自动定位、分割、识别与可视化。
核心思路：提前制备数字 0-9 标准模板 → 对银行卡图像做预处理增强卡号特征 → 筛选出卡号区域 → 逐字符模板匹配 → 输出识别结果。
适用于 CV 入门学习、视觉预处理实战、模板匹配算法应用。

五、🔥 项目核心原理（超详细版）
整个项目分为 5 大核心阶段，每一步都有明确的视觉算法目的：
阶段 1：数字模板提取与预处理
作用：生成标准的 0-9 数字模板库，为后续匹配做准备
读取模板图：加载白底黑字的 0-9 数字图片
灰度化：消除色彩干扰，将 3 通道彩色图转为 1 通道灰度图
反向二值化：将数字变为白色（前景），背景变为黑色（适配银行卡数字特征）
轮廓检测：提取每个数字的外轮廓
轮廓排序：按从左到右排序，保证模板顺序为 0、1、2...9
统一尺寸：将所有数字缩放为固定大小 (57,88)，保证匹配一致性
阶段 2：银行卡图像预处理（核心！增强卡号特征）
银行卡原始图存在背景干扰、颜色复杂、数字对比度低等问题，必须通过预处理突出卡号：
图像缩放：统一缩放到宽度 600，适配小尺寸图片，稳定后续轮廓参数
灰度化处理：去除彩色信息，降低计算量
礼帽操作（TopHat）
原理：原始图像 - 开运算结果
作用：突出亮部的卡号区域，抑制深色背景干扰
Sobel 水平边缘检测
原理：计算水平方向像素梯度变化
作用：银行卡数字为水平排列，仅保留水平边缘，过滤垂直干扰
图像归一化：将像素值统一到 0-255，增强对比度
闭运算
原理：膨胀 → 腐蚀
作用：将 4 个连续数字连接成一个整体矩形，方便后续批量筛选
二值化：自动计算阈值，将图像转为纯黑白，去除噪点
阶段 3：轮廓检测与卡号区域筛选
预处理后，图像中会出现多个矩形轮廓（卡号、日期、logo 等），通过规则过滤出卡号：
检测所有外轮廓：获取图像中所有矩形区域
宽高比筛选：银行卡 4 位数字组的宽高比固定在 2.5~5.0
尺寸筛选：过滤过小 / 过大的无效区域（宽 65-180，高 15-40）
排序：将筛选后的 4 组卡号按从左到右排序
阶段 4：单字符分割与模板匹配
字符分割：将一组 4 位数字，分割为单个独立字符
归一化模板匹配（TM_CCOEFF_NORMED）
核心算法：将待识别字符与 0-9 标准模板逐一对比
计算相似度得分，得分最高的模板数字即为识别结果
优点：不受光照、对比度轻微影响，识别准确率高
阶段 5：结果可视化绘制
每组数字仅绘制 1 次矩形框（避免重复重叠）
在矩形上方标注完整的 4 位数字
输出最终标注图像

七、常见报错解决方案
1. 图片读取失败（can't open/read file）
原因：图片未放入 img 文件夹 / 文件名错误
解决：图片必须命名为 模板.jpg、图片.jpg，并放在 img 文件夹内
2. imshow 断言失败
原因：图像加载为空
解决：检查图片格式（支持 JPG/PNG）、路径是否正确
3. 识别框 / 文字重叠
原因：绘图代码放入内层循环
解决：使用本项目提供的完整代码（已修复该问题）
4. 识别不到卡号
解决：微调轮廓筛选的宽高比、尺寸参数
