================================================================================
            基于 OpenCV 模板匹配的数字识别 - 项目说明
================================================================================

【项目简介】
本项目使用 OpenCV 实现简单的数字识别：先通过模板图像提取 0-9 数字的标准特征，
再对待识别图像中的数字区域进行模板匹配，最终输出识别结果并在图像上标出。

================================================================================
一、原理详解（详细过程）
================================================================================

1. 整体流程概览
   (1) 模板构建：从包含数字 0-9 的模板图片中提取每个数字的图像块，保存为模板字典。
   (2) 待识别图像预处理：增强数字区域、连接数字笔画、去除噪声、二值化。
   (3) 数字区域定位：找出所有可能的数字块（如银行卡号、票据编号）。
   (4) 数字分割与识别：在每个数字块内进一步分割单个数字，与模板匹配，取最高得分。
   (5) 结果可视化：在原图上绘制识别框和识别出的数字串。

2. 模板构建原理
   - 读取与灰度化
     cv2.cvtColor(img, cv2.COLOR_BGR2GRAY) 转为单通道灰度图，减少计算量。

   - 二值化
     cv2.threshold(ref, 0, 255, cv2.THRESH_BINARY_INV | cv2.THRESH_OTSU)[1]
     * THRESH_OTSU：自动计算最佳阈值（适合双峰直方图）。
     * THRESH_BINARY_INV：使数字变为白色（255），背景黑色（0），便于轮廓检测。

   - 轮廓检测
     cv2.findContours(ref, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
     * RETR_EXTERNAL：只检测最外层轮廓，忽略内部孔洞（如数字0的内圈）。
     * CHAIN_APPROX_SIMPLE：压缩冗余点，只保留端点。

   - 轮廓排序
     imutils.contours.sort_contours(refcnts, method="left-to-right")
     确保轮廓从左到右排列，与数字顺序一致。

   - 提取 ROI 并统一尺寸
     对每个轮廓计算外接矩形 cv2.boundingRect()，截取数字区域，缩放到固定大小
     (57,88) 作为模板。统一尺寸是因为模板匹配要求模板与待匹配区域尺寸相同。

3. 待识别图像的预处理原理
   预处理目标：突出数字区域、消除背景干扰、将分离的数字笔画连接成完整数字块。

   (1) 礼帽操作（Top Hat）
       tophat = cv2.morphologyEx(gray, cv2.MORPH_TOPHAT, rectKernel)
       公式：礼帽 = 原图 - 开运算(原图)
       作用：提取比周围区域明亮的细节。在暗背景亮数字的图像中增强数字。
       核大小 rectKernel = (9,3)：水平方向较长，适用于银行卡号等水平排列的数字。

   (2) Sobel 边缘检测
       gradX = cv2.Sobel(tophat, cv2.CV_64F, 1, 0, ksize=-1)
       gradX = cv2.convertScaleAbs(gradX)
       原理：计算 x 方向一阶导数，突出垂直边缘（数字左右两侧的边界）。
       ksize=-1 使用 3×3 Scharr 核，对边缘更敏感。
       最后归一化到 0~255：cv2.normalize(gradX, None, 0, 255, cv2.NORM_MINMAX)

   (3) 闭运算（连接数字）
       gradX = cv2.morphologyEx(gradX, cv2.MORPH_CLOSE, rectKernel)
       公式：先膨胀后腐蚀
       作用：填充数字内部小空隙，连接相近数字笔画，使整个数字块连成一片。
       水平长核 (9,3) 横向连接相邻数字，不影响垂直方向。

   (4) 二值化与二次闭运算
       thresh = cv2.threshold(gradX, 0, 255, cv2.THRESH_BINARY | cv2.THRESH_OTSU)[1]
       thresh = cv2.morphologyEx(thresh, cv2.MORPH_CLOSE, sqKernel)
       * OTSU 二值化：自动将梯度图转为黑白，数字区域为白色。
       * 二次闭运算：方形核 (5,5) 填补数字内部可能存在的空洞（如8、0的中心）。

4. 数字区域定位原理
   - 轮廓检测：cv2.findContours(thresh, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
   - 筛选条件：
        ar = dw / float(dh)           # 宽高比
        if 2.5 < ar < 5.0:            # 数字块通常较宽
            if 65 < dw < 180 and 15 < dh < 40:
     * 宽高比范围根据实际任务调整（例如信用卡号比单个数字宽数倍）。
     * 宽度和高度范围取决于图片缩放后的像素值（代码中用 width=600 统一缩放）。
   - 排序：sorted(locs, key=lambda x: x[0]) 按左上角 x 坐标从左到右排序。

5. 单个数字识别原理
   (1) 数字块内再次分割
       group = gray[zy-5:zy+zh+5, zx-5:zx+zw+5]          # 扩展5像素避免切割过紧
       group = cv2.threshold(group, 0, 255, cv2.THRESH_BINARY | cv2.THRESH_OTSU)[1]
       digitcnts, _ = cv2.findContours(group, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
       digitcnts = contours.sort_contours(digitcnts, method="left-to-right")[0]
       对每个数字块先二值化，再找轮廓，分离出单个数字（如“1”、“2”等）。
       再次从左到右排序，确保识别顺序正确。

   (2) 模板匹配
       result = cv2.matchTemplate(roi, digitROI, cv2.TM_CCOEFF_NORMED)
       (_, score, _, _) = cv2.minMaxLoc(result)
       方法：TM_CCOEFF_NORMED 是归一化相关系数匹配，输出范围 -1~1，越接近1越相似。
       原理：待匹配数字 ROI（57×88）在模板图像上滑动，因尺寸相同只有一个位置，
             直接得到相关系数作为相似度分数。
       选取最佳匹配：对 0-9 共10个模板分别计算分数，取 np.argmax(scores) 作为结果。

6. 结果绘制
   - 在原图上绘制绿色矩形框（外扩5像素）。
   - cv2.putText 在矩形上方显示识别出的数字串。

四、使用步骤
================================================================================
1. 准备模板图片
   - 确保“模板.jpg”中包含清晰的印刷体数字0-9，背景干净，数字按顺序水平排列。
   - 建议尺寸：每个数字约57×88像素，整体宽度约570~600像素。

2. 修改图片路径
   打开脚本，修改以下两行路径：
     img = cv2.imread(r'你的模板图片路径')
     input = cv2.imread(r'你的待识别图片路径')

3. 运行脚本
     python digital_recognition.py

4. 观察中间结果
   脚本中多次调用 cv_show() 会显示处理过程中的图像（按任意键继续），方便调试。

5. 获取最终结果
   最后显示的图像上会标出识别出的数字串。

五、参数调整说明（针对不同图片）
================================================================================
+--------------------------+--------------------------------+-------------------+
| 参数位置                 | 含义                           | 调整建议           |
+--------------------------+--------------------------------+-------------------+
| rectKernel = (9,3)       | 礼帽和闭运算的水平核            | 数字间距大时增宽度 |
| sqKernel = (5,5)         | 二次闭运算的方形核              | 内部空洞大时增大核 |
| ar > 2.5 and ar < 5.0    | 数字区域宽高比范围              | 根据实际数字块调整 |
| dw > 65 and dw < 180     | 数字区域宽度（像素）            | 根据图片中宽度调整 |
| dh > 15 and dh < 40      | 数字区域高度（像素）            | 根据图片中高度调整 |
| roi.resize((57,88))      | 模板与待匹配数字的统一尺寸       | 必须与模板实际一致 |

六、常见问题与注意事项
================================================================================
- 模板数字顺序错误：必须确保模板图片中的数字是从左到右排列的0~9。
- 识别结果不准确：字体差异大 → 更换更相似模板；预处理参数不合适 → 调整核大小。
- 中间步骤图像全黑/全白：检查 THRESH_BINARY_INV 是否使用正确；礼帽是否有效。
- 性能问题：本方法适合固定场景、少量数字。实时或复杂背景建议改用深度学习。

================================================================================
七、改进方向
================================================================================
- 自适应缩放：根据轮廓高度动态调整模板缩放比例，提高对不同字号的鲁棒性。
- 增加旋转校正：使用最小外接矩形检测倾斜角度，进行仿射变换校正。
- 深度学习替代：使用 MNIST 预训练模型或 Tesseract OCR 提高泛化能力。
- 支持小数点或符号：扩展模板库并修改筛选逻辑。
